# Trademark policy

The **code** in this repository is open source under [Apache-2.0](LICENSE). The **name** is not.

"Alethic" and the Alethic logo are trademarks of the copyright holder. The Apache License covers
copyright and patents, and explicitly does not grant trademark rights ([section 6](LICENSE)). This
file says what that means in practice, so nobody has to guess.

## You do not need permission to

- Use Alethic, for anything, including commercially.
- Fork the code, modify it, and distribute your version — **under a different name**.
- Say truthfully what your project is: "a fork of Alethic", "based on Alethic", "works with
  Alethic", "an Alethic plugin". Describing a relationship is not claiming the name.
- Write about Alethic, review it, teach it, screenshot it.

## Please do not

- Ship a fork, a modified build, or a competing product **called Alethic**, or under a name close
  enough to be mistaken for it.
- Use the name or logo in a way that suggests your project is the official one, or that it is
  endorsed by or affiliated with this project.
- Register "Alethic" (or a confusingly similar mark) as a trademark, domain, package name, or app
  store listing for a similar product.

## Why this exists

An open licence and a protected name are not in tension — they do different jobs. The licence makes
sure the work stays usable by anyone. The name makes sure that when someone downloads "Alethic",
they get this project and not something else wearing its face. Rust, Docker and Firefox all draw
the line in the same place.

If you are unsure whether your use is fine, ask first — open an issue. Reasonable requests get a
yes.
